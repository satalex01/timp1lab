\# Проверка функции B



\## Цель



Вывести сведения обо всех студентах и вычислить сумму их баллов.



\## Основной набор



Входные данные:



\- anna — 49

\- boris — 50

\- vera — 80

\- gleb — 100



Ожидаемый результат:



anna; score=49

boris; score=50

vera; score=80

gleb; score=100

SumScore: 279



Фактический результат совпадает с ожидаемым.



\## Проверка пустого массива



Ожидаемый результат:



SumScore: 0



Функция Build возвращает SumScore: 0 для пустого массива.
